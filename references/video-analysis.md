# 视频拆解标准

## 获取与证据

1. 从用户消息或 Obsidian 文档提取全部链接，保留来源文件和行号。
2. 解析短链并按最终视频身份去重；无法解析时按原链接临时编号。
3. 优先获取完整口播/字幕、0–3秒画面、封面标题、镜头顺序、时长、账号/品牌，以及页面真实可见的互动或销售数据。
4. 页面只显示标题时，只分析标题与可见信息，并标注“内容未取得”。
5. 避免长篇逐字引用；保存分析所需的短句和时间点即可。

## 单条拆解字段

| 字段 | 要回答的问题 |
|---|---|
| 样本编号 | 原始链接、最终链接、是否重复 |
| 目标用户 | 谁使用、谁购买、年龄/地域/职业/场景 |
| 0–3秒开头 | 点名谁、什么冲突、什么动作或证据 |
| 核心痛点 | 身体、功能、情绪/社交、购买风险 |
| 旧方案失败 | 用户过去怎样解决，为什么仍失败 |
| 核心承诺 | 视频最想让用户记住的一个结果 |
| 证据链 | 材质、结构、动作、对比、数字、多人证言 |
| 异议处理 | 价格、真实性、尺码、舒适、耐用、边界 |
| CTA | 现在行动的理由 |
| 结构标签 | 开头类型、主体框架、底层心理 |

## 跨样本归纳

- 共性指出出现次数或样本编号，不把单例写成规律。
- 同时找共性和差异：共性解释品类基础，差异解释竞争突破口。
- 爆量原因拆为获得停留、维持完播、建立相信、推动行动四段。
- 数据不可见时使用“可能提升”“待验证”，不用“证明爆量”。
- 说明样本局限：样本量、来源偏差、季节、账号体量、投流等未知因素。
