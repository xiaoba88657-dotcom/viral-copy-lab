# 爆款框架库

## 默认结构

`精准人群/关系点名 → 高压场景与后果 → 旧方案失败 → 单一承诺 → 三组可视证据 → 核心异议 → 行动理由`

这是分析起点，不是机械模板。若样本展示更有效结构，记录其适用条件。

## 开头判断

强开头通常包含以下三项中的两项以上：

- **具体的人**：年龄、地域、职业、关系或使用身份。
- **具体的压力**：极寒、时间、身体后果、尴尬、损失或旧方案失败。
- **具体的反常结果/证据**：一条顶三条、很重却不臃肿、羊毛贴身却不扎、现场拆解或动作测试。

常用公式：

- `谁的/谁家 + 关系对象 + 高危场景 + 后果`
- `地域/职业 + 极端条件 + 反常结果`
- `先别买/别只看X + 揭露旧认知错误`
- `数字/破坏性动作 + 直接证明`
- `用户原话/评论问题 + 当场验收`

## 证据优先级

1. 同条件真人或产品 AB 对比。
2. 动作、时间、长度、重量等可复核测试。
3. 产品拆解、微距、翻面和结构展示。
4. 多人物/多场景证言。
5. 主播口头描述。

参数必须翻译：材质变成皮肤体验，重量变成保暖可信度，工艺变成不扎/不勒/不卡，科技名词变成可观察结果。

## 四段爆量逻辑

- **停留**：让我立刻觉得“说的是我”。
- **完播**：设置比较、悬念、测试规则或连续新证据。
- **相信**：给出同条件、可复核、不过度包装的证据。
- **行动**：降低风险并给出下一步理由；不得虚构稀缺。

## 框架成熟度

- `候选`：至少2个独立样本重复出现。
- `强候选`：多个账号/产品重复，且与用户痛点一致。
- `已验证`：有实际投放数据支持或跨产品复现。
- `失效/有边界`：测试无效或仅在特定条件下成立。
